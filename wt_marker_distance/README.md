# WT Marker Distance — оверлей расстояния до метки отряда (War Thunder)

Небольшая утилита на Python: находит жёлтую метку «Указать цель» (маркер взвода)
на экране, определяет её позицию относительно центра экрана и показывает
**расстояние от вас до метки + азимут** поверх игры в виде прозрачного
клик-сквозь оверлея.

> ⚠️ Это внешний инструмент компьютерного зрения. War Thunder может засчитывать
> чтение памяти игры как чит — поэтому здесь **никакого вмешательства в процесс
> игры**: только анализ пикселей экрана и рисование своей оверлей-окном.
> Используйте на свой риск, дистанция является **оценкой** (калибруется под вас).

## Как это работает

1. `mss` захватывает экран ~30 FPS.
2. OpenCV конвертит кадр в HSV и ищет жёлтые blobs (HSV-детект + морфология +
   контуры) в заданной зоне ROI.
3. `MarkerTracker` сглаживает позицию метки между кадрами.
4. Расстояние = смещение метки от центра экрана × калибровочный коэффициент
   `m_per_px` с поправкой на перспективу/зум (`fov_deg`).
5. Прозрачное topmost-окно (WinAPI layered window, клик сквозь) рисует рамку
   вокруг метки, пунктирную линию от прицела и текст `1271 м  азимут 56°`.

## Установка (Windows)

```bat
cd wt_marker_distance
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Linux/macOS тоже запускается (для разработки), но настоящий оверлей —
только Windows; там печатается заглушка в консоль.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F8`  | показать / скрыть оверлей |
| `F9`  | зафиксировать текущую метку как цель (не будет терять при пропадании) |
| `F10` | сбросить цель |
| `Esc` | выход |

## Калибровка точности

Дистанция по пикселям — величина оценочная, настройте её под себя один раз:

1. Поставьте метку на объект, расстояние до которого известно (в бою WT пишет
   дистанцию до врагов; либо ориентируйтесь по миникарте).
2. Подкрутите `m_per_px` в `config.json`, пока показания оверлея не совпадут.
3. Сузьте зону поиска, чтобы детектор не ловил жёлтые элементы HUD:
   сохраните скриншот игры в `calib/screenshot.png` и выполните
   `python calib/calibrate.py --roi` — выделите рамкой область, куда летят маркеры.
4. Проверьте качество детекции: `python calib/calibrate.py` (автотест на
   синтетических кадрах, среднее смещение < 12 px = OK).

### Параметры `config.json`

| Ключ | Описание |
|------|----------|
| `roi` | зона поиска метки на экране (пиксели); `null` = до края |
| `hsv_h_min/max`, `hsv_s_min/v_min` | фильтр цвета маркера (по умолчанию — жёлтый) |
| `min_area`, `max_area` | размеры blob в пикселях |
| `detect_every` | детектировать каждый N-й кадр (экономия CPU) |
| `marker_ttl` | сек., сколько держать цель после потери метки |
| `m_per_px` | **главная калибровка**: метров на 1 пиксель смещения |
| `fov_deg` | горизонтальный FOV (поправка перспективы по краям экрана) |
| `overlay_opacity`, `font_size` | внешний вид оверлея |
| `hotkey_*` | свои клавиши |

## Структура

```
wt_marker_distance/
├── main.py          # цикл: захват → детект → расчёт → оверлей, хоткеи
├── detector.py      # mss-захват, HSV-детект маркера, трекер сглаживания
├── overlay.py       # прозрачное окно WinAPI (GDI), заглушка для dev
├── config.py        # JSON-конфиг
├── calib/calibrate.py  # автотест точности + интерактивная ROI
└── requirements.txt
```

## Известные ограничения

- Метка за деревьями/дымом теряется — держится `marker_ttl` секунд.
- Если на экране несколько жёлтых объектов — берётся самый крупный в ROI.
- Перспектива WT не плоская: цифры приближённые, для снарядов САУ лучше
  сверяться с внутриигровой разметкой.
